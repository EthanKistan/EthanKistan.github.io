03 · Featured work

Sacks Packaging LMS

A logistics management system for a Durban packaging manufacturer. It replaces a shared spreadsheet, a second fleet sheet and WhatsApp status updates with one Windows desktop app backed by an API and database on Microsoft Azure.

Customer service plans the week and hands it to logistics. Dispatch allocates trucks, and a truck that is already out can't be booked twice. Deliveries are tracked live and closed with a signed proof of delivery. The team chats inside the app.

  • C#
  • .NET 10
  • WPF
  • ASP.NET Core
  • EF Core
  • Azure SQL
  • GitHub Actions
Read the case study Watch the presentation

Team of six · 2026 · Source is private because it was built for a client; available on request.

The backend

Designed and built the ASP.NET Core API and EF Core data layer, then migrated allocation, scheduling, history, users, documents and the distribution plan off local files onto it.

Live fleet tracking

Vehicle positions from the Cartrack API on an OpenStreetMap map, polled every 5 seconds, with telemetry, trip history, geofence status and ETA to the delivery point.

Security

JWT sign-in with passwords verified on the server, and per-screen permissions enforced on every API request, not only hidden in the menu.

Quality

Integration tests against a real SQL Server container, plus Sonar and Snyk scanning in the CI pipeline. Traced a vanishing-reactions bug to a chat SDK defect and worked around it.
